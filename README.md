## 怎麼開啟

直接用瀏覽器開啟 `index.html` 即可。

若要透過本機伺服器（勾選狀態的儲存行為比較標準）：

```bash
npx --yes serve ai-literacy-notes -l 4321
```

然後開 <http://localhost:4321>。
