# COROS FIT 匯出摘要工具

把 COROS Training Hub 匯出的一整包 `.fit` 檔，壓縮成單一 CSV 摘要。

原始 FIT 檔是逐秒紀錄的二進位格式，一趟 40 分鐘的跑步就有兩千多筆資料點，
上百筆活動動輒數百 MB。這支腳本把每筆活動濃縮成一列（48 個欄位），
輸出通常只有幾十 KB，方便備份、分享、或丟進試算表畫圖。

## 安裝與執行

```bash
pip install fitdecode
python3 coros_summary.py ~/Downloads/exportsportdata -o coros_summary.csv
```

會遞迴搜尋子資料夾，同時支援 `.fit` 和 `.fit.gz`。
同一筆活動重複匯出時會自動去重（依日期＋時間＋時長＋距離判斷）。
單一檔案解析失敗不會中斷整批，最後會列出失敗清單。

| 參數 | 說明 |
|---|---|
| `-o, --output` | 輸出 CSV 路徑，預設 `coros_summary.csv` |
| `--tz` | 本地時區相對 UTC 的時差，台灣是 `8`（預設值） |
| `--quiet` | 不印逐筆進度 |

執行完除了產生 CSV，也會直接在終端機印出期間、總距離、總時數、
運動類型分布，以及效率指數最高的那一筆。

## 欄位說明

基本欄位（日期、距離、配速、心率、步頻、功率、爬升⋯）之外，
有幾個是這支腳本自己算的：

**`efficiency_index`（效率指數）— 每一次心跳前進幾公尺**

跨時期比較有氧體能最公平的指標。它同時消掉了「配速」和「努力程度」的干擾：
單看配速，天氣熱或狀況差的日子會失真；單看心率，又不知道換到多少距離。
數值越高代表同樣的心臟負擔跑得越遠。

**`hr_drift_bpm`（心率漂移）— 後半段平均心率減前半段**

**`decoupling_pct`（心率脫鉤）— 後半段的「速度／心率」比值相對前半段的變化**

有氧基礎紮實時，配速與心率的關係在整趟運動中應該維持穩定。
一般以絕對值 5% 為界：負值越大，代表越到後段越「花更多心跳換同樣速度」，
是有氧耐力不足或當天狀況不佳的訊號。短時間、高溫下的數值會偏差，看趨勢比看單次可靠。

**`hr_*_s`（心率分箱）— 每 10 bpm 一格的停留秒數**

從 80–89 到 190+ 共 12 格，可直接用來算心率區間佔比、
檢查輕鬆跑是不是真的跑在輕鬆區間。

## 隱私

CSV 只保留每筆活動的**起點**經緯度（`start_lat` / `start_lon`），
不含完整 GPS 軌跡。如果連起點都不想外流，分享前把這兩欄刪掉即可。
